# xCore OS

**Версия: Alpha 1.1.0**
**Дата: 8 июня 2026**
**Статус: Alpha**

## Описание

xCore OS — простая операционная система в стиле Windows 8 с экраном загрузки, оконной системой и встроенными приложениями.

## Что нового в Alpha 1.1.0

- Экран загрузки — чёрный фон, логотип XOS, жёлтый прогресс-бар
- Сворачивание окон — кнопка "-" в каждом окне
- Перезагрузка системы — кнопка в Charms
- Счётчик окон — показывает сколько окон открыто

## Возможности

- Интерфейс с плитками в стиле Windows 8
- Смена обоев (w0, w1, w2)
- 6 встроенных приложений
- Сохранение настроек в localStorage
- Charms (чудо-панель)
- Горячие клавиши

## Горячие клавиши

| Сочетание | Действие |
|-----------|----------|
| Alt + C | Открыть Charms |
| Alt + S | Открыть боковую панель |
| Alt + F4 | Закрыть активное окно |
| Esc | Закрыть Charms |
