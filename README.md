# xCore OS

**Версия: os-070626 (pre-alpha)**
**Дата: 7 июня 2026**

## Описание

xCore OS - простая операционная система в стиле Windows 8. Создана для изучения и экспериментов.

## Возможности

- 🖥️ Интерфейс с плитками (как в Windows 8)
- 🎨 Смена обоев (w0.svg, w1.svg, w2.svg)
- 📦 Встроенные приложения:
  - Калькулятор
  - Заметки (с сохранением)
  - Браузер
  - Выбор обоев
- 💾 Сохранение настроек в localStorage
- 🔍 Чудо-панель (Charms)
- 🪟 Окна приложений (можно перетаскивать)

## Установка и запуск

### Локально:
1. Скачай репозиторий
2. Открой `index.html` в браузере
3. Нажми `F11` для полноэкранного режима

### Онлайн:
https://green-glitch-cmyk.github.io/xCore-OS/

## Управление

- **Клик по плитке** - открыть приложение
- **Кнопка Пуск** - открыть панель
- **Значок** - открыть панель
- **Клик вне панели** - закрыть её
- **Перетаскивание заголовка окна** - переместить окно
